Funciones

Todo lo que necesitas, sin ruido.

Una app pensada para organizar lo que estudias, lo que haces y lo que se te ocurre.

📓

Cuadernos y conjuntos

Organiza tus notas en cuadernos de colores y agrúpalas en conjuntos dentro de cada uno.

🧱

Editor por bloques

Texto, listas, títulos e imágenes. Mueve bloques arrastrándolos y pliega las secciones que no uses.

✅

Tareas con prioridad

Fechas, horas, prioridades y adjuntos. Una vista de próximas tareas te dice qué atender primero.

📅

Calendario

Mira las notas y tareas de cada día de un vistazo.

🌗

Modo claro y oscuro

Sigue la configuración de tu sistema, con colores pensados para leer a gusto.

🔒

Privada por diseño

Sin cuentas ni servidor. El código es público, así que puedes comprobarlo tú mismo.

Abrir BrownieNote

Compilar desde el código

Hazla tuya.

Necesitas Flutter. Estos son los pasos:

  1. Clona el repogit clone https://github.com/oscarrdel/BrownieNote.git
  2. Instala dependenciascd BrownieNote/browninote y luego flutter pub get
  3. Ejecútalaflutter run, o flutter run -d chrome para la versión web
git clone https://github.com/oscarrdel/BrownieNote.git
cd BrownieNote/browninote
flutter pub get
flutter run
