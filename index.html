BrownieNote

Notas y tareas en un solo lugar, hechas con Flutter. Tus datos se guardan en tu dispositivo: no necesitas cuenta ni conexión.

Esta página es una demostración. BrownieNote es una app de código abierto que muestra lo que se puede construir con Flutter. Es un ejemplo de mi trabajo como desarrollador, no un servicio en línea.

Lo que incluye

  • Cuadernos y conjuntos de notasOrganiza tus notas en cuadernos y agrúpalas en conjuntos.
  • Editor por bloquesTexto, listas, títulos e imágenes en bloques.
  • Tareas con prioridadFechas, horas, prioridades y adjuntos. Vista de próximas tareas.
  • CalendarioRevisa las notas y tareas de cada día.
  • Modo claro y oscuroSigue la configuración de tu sistema.

Descargarla

Versión de escritorio para Windows (64 bits). Descomprime el zip y ejecuta browninote.exe.

Descargar BrownieNote para Windows

Probarla

El código está en GitHub. Para ejecutarla en tu computadora necesitas Flutter:

git clone https://github.com/oscarrdel/BrownieNote.git
cd BrownieNote/browninote
flutter pub get
flutter run
